# GCP Landing Zone — Interview Prep

This repository collects notes, articles, cheatsheets, diagrams, and scripts to prepare for interviews focused on GCP Landing Zones and related platform design topics.

Structure
- `articles/` — long-form articles and study notes (templates & samples)
- `cheatsheets/` — short checklists and quick-reference guides
- `resources/` — curated links and external references
- `diagrams/` — architecture diagrams and assets
- `scripts/` — example scripts, Terraform snippets, automation helpers

Usage
- Read `articles/` and `cheatsheets/` for study.
- Add new articles using `articles/TEMPLATE.md`.
- Submit PRs or add issues for missing topics.

Contributing
- Keep articles concise and focused on interview-friendly topics.
- Use the template in `articles/TEMPLATE.md` for consistency.
